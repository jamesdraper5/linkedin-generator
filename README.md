Want to impress everyone with how clever and insightful you are on LinkedIn without actually being clever or insightful? That's what AI is for! Start up the app, then enter the URL of a blog post or article into the form. (I'd recommend you actually read the article first but I'm not your Mom). Then click Generate and it will produce a short insightful paragraph on the article which you can copy and post to LinkedIn.

## Getting Started

First, you need to get an OpenAI API key and save it to a `.env` file in the top level directory. 
Then, just run the development server like so:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
